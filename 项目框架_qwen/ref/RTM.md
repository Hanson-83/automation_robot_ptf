# RTM.md — 需求追踪矩阵（Requirements Traceability Matrix）

> **文档性质**：追踪每条需求从提出到验收的全生命周期状态，保证"需求 → 设计 → 实现 → 测试 → 验收"双向可追溯。
> **维护策略**：动态更新。需求变更、设计/实现/测试状态变化时同步更新（联动规则见 [`workflow.md`](workflow.md) 第 3 节）。
> **上游文档**：需求定义见 [`requirements.md`](requirements.md)。
