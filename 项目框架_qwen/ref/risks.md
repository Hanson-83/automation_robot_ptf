# risks.md — 风险登记册

> **文档性质**：项目风险清单及应对策略（风险内容较多时从 [`progress.md`](progress.md) 拆分独立维护）。
> **维护策略**：动态更新。识别新风险、风险状态变化时更新；由任何 Agent 上报、主 Agent 汇总维护。
> **风险字段说明**：
> - **可能性**：高/中/低（发生概率）
> - **可观察性**：高/中/低（能否在造成影响前被察觉——低可观察性风险需重点设置监测手段）
> - **影响**：高/中/低（对进度/成本/质量/安全的影响）
> - **等级**：可能性 × 影响 综合评估（高/中/低）
> - **应对策略**：规避/转移/减轻/接受
> - **状态**：识别/监控中/已缓解/已发生（转 issue）/已关闭

## 2. 风险类别说明

- **技术风险**：技术方案不可行、性能不达标、软硬件兼容性问题等；
- **进度风险**：关键路径延误、依赖外部交付延迟等；
- **资源风险**：人力/AI Agent 算力/预算不足、关键设备到货延迟等；
- **安全风险**：人身安全、数据安全、系统安全相关；
- **外部风险**：供应商、客户需求变化、法规标准变化等。
