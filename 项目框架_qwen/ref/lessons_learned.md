# lessons_learned.md — 经验教训

> **文档性质**：项目执行过程中积累的经验教训（踩坑、最佳实践、平台使用心得等）。
> **维护策略**：动态更新，只增不删。每条经验应可复用、可检索。
> **价值定位**：本文件是团队与 Agent 群体的"集体记忆"，新会话/新平台 Agent 可通过检索本文件避免重复踩坑。

## 记录规范

每条记录包含：日期、类别、场景、教训/经验、建议做法。类别包括：
- **技术类**：技术选型、实现方法、疑难杂症、软硬件集成；
- **流程类**：工作流、文档协作、多 Agent 协作模式；
- **平台类**：各 AI Agent 平台（Claude Code/Cursor/Codex 等）的使用心得与坑；
- **环境类**：开发/测试/部署环境的坑与注意事项；
- **管理类**：估时、沟通、验收的经验。
