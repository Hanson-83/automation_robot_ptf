# Issues — 问题清单

> **定位**：**动态更新**项目执行过程中遇到的问题清单，含问题描述、状态、解决方案。
> **更新频率**：高频（发现问题即登记，解决即更新）。
> **处理流程**：发现 → 登记 → 分析根因 → 制定/实施解决方案 → 验证 → 关闭。阻塞性/高风险问题同步升级到 progress.md 与 risks.md。

## 3. 状态说明

- **开放**：已登记未处理；**分析中**：正在定位根因；**修复中**：已实施修复未验证；**已解决**：验证通过待关闭；**已关闭**：确认解决并复核。
- 关闭前必须完成验证，并附验证方式与结果。

## 4. 升级规则

- 影响里程碑达成或阻塞其他任务 → 同步更新 progress.md。
- 可能造成损失/返工/交付风险 → 同步登记 risks.md。
- 高影响问题解决过程与结论 → 沉淀到 lessons_learned.md 与 technical_manual.md（疑难杂症部分）。
