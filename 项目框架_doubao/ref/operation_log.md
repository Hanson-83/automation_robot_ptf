# Operation Log — 操作日志

> **定位**：**动态记录**项目执行过程中**有风险、需追踪**的操作，如：修改、新增、删除、登入、登出、启用、禁用、停止、部署、发布、回滚、权限变更等。
> **更新频率**：按需（每次高风险操作前后登记）。
> **原则**：**先留痕后操作**（能预登记则预登记）；操作完成后回填结果；本文件是追溯审计的依据。

## 3. 操作类型说明

- **新增/修改/删除**：文件、代码、配置、数据、资源。
- **启用/禁用/停止**：服务、任务、定时任务、功能开关、账号。
- **登入/登出**：各环境、各平台账号会话。
- **部署/发布/回滚**：环境发布、版本切换、回滚操作。
- **权限变更**：授权/撤销、成员变更、密钥轮换。

## 4. 记录规则

- 判断标准：操作**不可自动撤销、影响共享系统、可能造成损失、涉及权限/安全**即属于需记录范畴。
- 风险等级：高（影响生产/数据/对外）、中（影响共享开发/测试环境）、低（仅影响个人工作区）。
- 涉及凭据类操作（登入/登出/授权）只记录「何时、谁、对什么资源做了何操作」，**不记录**凭据内容本身。
