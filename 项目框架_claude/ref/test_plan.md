# Test Plan — 测试规划（可选）

> **定位**：测试策略、用例、准入/准出、安全测试。 · **更新频率**：中频 · **启用条件**：测试内容超出 [`plan.md`](plan.md) 可承载时拆出；否则内联在 plan.md。 · **上游**：[`requirements.md`](requirements.md)、[`plan.md`](plan.md) · **缺陷路由**：[`issues.md`](issues.md)
> **原则**：测试前置——开发前先规划测试（见 [`AGENTS.md`](../AGENTS.md) §3.2）。

## 1. 测试策略（分层）

| 层级 | 范围 | 环境 | 说明 |
|---|---|---|---|
| 单元 | 函数/模块 | DEV | 快速反馈 |
| 集成 | 模块间/接口 | TEST | 含 **SIL**（软件在环）、**HIL**（硬件在环） |
| 系统 | 端到端 | TEST/STAGING | 仿真优先 → HIL → 现场 |
| 验收 | 需求验收 | STAGING/现场 | SAT/UAT，高风险由人类执行 |

## 2. 准入/准出标准

- **准入**：被测功能开发完成、依赖就绪、测试环境可用。
- **准出**：P0 用例 **100%** 通过、P1 **≥95%**、**无未处置的高风险缺陷**。
