# Operation Log — 高风险操作审计

> **定位**：高风险操作的审计留痕，强制流程 **登记 → 批准 → 执行 → 记录**。 · **更新频率**：按需（每次高风险操作） · **上游**：[`AGENTS.md`](../AGENTS.md) §5.1、§6
> **⚠ 凭据不入日志**：本文件严禁记录任何密钥/密码明文。

## 1. 适用范围（何时必须登记）

涉及以下之一即须登记并获批准（见 [`workflow.md`](workflow.md) 必停点）：
- **人身安全**：机器人运动、设备上电、急停旁路；
- **数据安全**：删除/覆盖/迁移数据、格式化；
- **系统安全**：生产/现场环境变更、部署上线；
- **不可逆 Git 操作**：`reset --hard`、`push --force`、`rebase`、删分支。
